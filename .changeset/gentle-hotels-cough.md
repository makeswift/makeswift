Rebuilds the underlying mechanisms that are used to generate CSS and handle dynamic style updates to Makeswift content.

React 19 is now required. This is because the new CSS engine depends on stylesheet hoisting behaviors introduced in React 19. This also means that Next.js hosts should be on Next.js 15 or later, since earlier versions are incompatible with React 19.

Prior to these changes, the `<RootStyleRegistry/>` could be omitted in certain scenarios (`nextjs-pages-router` hosts). This is no longer the case. A `<RootStyleRegistry/>` must always be present in your application's Makeswift provider tree as a child of the `<ReactRuntimeProvider/>` in order for Makeswift content to render.

The runtime no longer utilizes an Emotion cache, and the signature of the `<RootStyleRegistry/>` component has changed accordingly. The `cacheKey` prop has been removed. We've introduced an optional `classNamePrefix` that can be used to set a custom prefix for all CSS class names generated by the Makeswift runtime. For example:

```typescript
  <ReactRuntimeProvider {...{ runtime, siteVersion, locale }}>
    <RootStyleRegistry classNamePrefix="my-class-prefix">{children}</RootStyleRegistry>
  </ReactRuntimeProvider>
```
